# Oshi Restaurant

Барномаи Android барои идоракунии ресторан бо ду панел — барои фармоишдиҳанда ва админ.

## Дар барнома
- Jetpack Compose + Material 3
- Меню, ҷустуҷӯ, сабад ва бронирование
- Омор, фармоишҳо, мизҳо ва идоракунии меню
- Аниматсияҳои зебо ва интерфейси адаптивӣ
- Ҳолати демо бидуни бекенд

## Иҷро кардан
1. Лоиҳаро дар Android Studio кушоед.
2. `Sync Project with Gradle Files`-ро анҷом диҳед.
3. Модули `app`-ро дар эмулятор ё телефон иҷро кунед.

Минималии Android: API 24.
